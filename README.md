## 联通线路常见问题

### CN2 GIA 就等于联通精品线路吗？

不等于。CN2 GIA 是中国电信的网络。搬瓦工官方对 USCA_9 另行列出联通 Premium（AS10099），对 CN2 GIA E-Commerce 则描述了面向中国联通的企业级传输。应按具体套餐页面理解，不能只凭“CN2 GIA”推断联通全程路由。

### 联通用户一定要买 E-Commerce 或 SLA 吗？

不一定。Basic 系列价格较低，但官网将其描述为通用网络方案，地点之间的中国方向连接可能不同。E-Commerce 的多数地点提供高级中国连接；SLA 则额外强调特定地点的可靠性承诺和网络冗余。若预算优先，先确认目标 Basic 地点的网络条件；若中国方向连接是主要需求，再比较对应的 E-Commerce 机房。不要为了套餐名称多付费，却没有确认你需要的那项线路能力。

### 换机房就一定会变快吗？

不一定。不同机房有不同上游网络和地理位置，但结果还受本地联通出口、时间段和目标网络影响。搬瓦工表示部分方案支持免费跨机房迁移；可迁移范围要按具体套餐核对。迁移后仍应重新测试，别只凭地区名称判断。

### 下单前该确认哪些信息？

至少检查套餐名称、数据中心代码、月流量、端口速度、计费周期、续费金额和可迁移地点。还要确认产品是否明确提到联通方向网络，以及退款或 SLA 条件是否适用于所选套餐。搬瓦工服务是自管理 VPS，系统安装和应用配置需要自行处理；其官方页面说明控制面板为 KiwiVM，提供启动、重装、快照和数据中心迁移等管理功能。
